Checklist interactiva de 5 pruebas

Audita cualquier herramienta gratis — before you type a real number into it

Abre la herramienta que estás evaluando en otra pestaña. Luego abre DevTools (Cmd+Opt+I / Ctrl+Shift+I). Corre estas cinco pruebas. Cada una es menos de un minuto. Tu estado de checkboxes se guarda en localStorage para retomar después.

Haz esto: En la pestaña de la herramienta, abre DevTools → Network. Limpia la lista. Teclea un dígito en cualquier campo.

Pasa: La pestaña Network se mantiene vacía.

Falla: Cada tecla POSTea al servidor. Vete.

Haz esto: Mira el área alrededor de los campos del formulario. ¿Hay una oración que te diga qué pasa con tus inputs?

Pasa: Una declaración de manejo de datos visible sin hacer scroll.

Falla: "Política de Privacidad" en el footer no es lo mismo.

Haz esto: Intenta usar la herramienta sin meter info personal. Intenta ver resultados.

Pasa: Sin gate. La herramienta funciona y ya.

Falla: "Ingresa tu correo para ver tus resultados." Tus números son el precio.

Haz esto: DevTools → Network → filtra JS. Recarga. Mira el dominio de cada script.

Pasa: Cada script es del dominio de la herramienta más, máximo, un proveedor privacy-first (Plausible, Fathom).

Falla: google-analytics.com, googletagmanager.com, facebook.net, hubspot.com, hotjar.com, fullstory.com, segment.io — tus inputs los están grabando.

Haz esto: Clic derecho → Ver código fuente. O abre el archivo JS principal desde DevTools → Sources.

Pasa: Sin minificar, nombres de funciones descriptivos, cada comentario está en el fuente.

Falla: Bundle minificado de 4 MB, variables de una letra, matemáticas escondidas en un dashboard de framework.

Puntaje: 0 / 5

Corre las pruebas arriba. Cada checkbox = un pase.

Subtipos de restaurante

El diagnóstico de restaurantes calibra el puntaje y el texto para diez segmentos. Cada subtipo mapea a tipos de schema.org, pistas de plataforma y un conjunto distinto de pesos para las revisiones prioritarias — a una pizzería le importa la comisión de los pedidos directos de una forma que a un comedor de alta cocina con menú de degustación no le importa, y viceversa. Estas entradas explican qué cubre cada segmento y cuándo aplica.

Términos

10 definiciones.

  • Alta cocina — menús de degustación, prix-fixe, mesa destino
  • Casual / servicio completo — bistró de barrio, comedor familiar
  • Fast-casual / servicio rápido — servicio de mostrador, para llevar
  • Café / cafetería — café de especialidad, tráfico de la mañana
  • Panadería / repostería — viennoiserie, pasteles personalizados, postres
  • Bar / pub / cervecería — taproom, gastropub, coctelería
  • Pizzería — napolitana, Detroit, siciliana, por porción
  • Food truck / pop-up — cocina móvil, por horario
  • Cocina fantasma / solo entrega — marca virtual, cloud kitchen
  • Solo catering / eventos privados — off-premise, drop-off, chef privado

Marca y diseño

El pequeño conjunto de palabras que todo dueño con un logo debería conocer antes de entregarlo a un diseñador, un desarrollador, una imprenta de rótulos o un proveedor de impresión. La mayoría son invisibles hasta que faltan.

Términos

11 definiciones.

  • Identidad de marca — el sistema visible completo alrededor de tu logo
  • Composición de logo (lockup) — símbolo + logotipo + lema opcional, como una unidad
  • Espacio de resguardo — la zona vacía alrededor del logo
  • Paleta de colores — el conjunto curado de colores que le pertenecen a tu marca
  • Contraste WCAG AA — contraste de color accesible
  • Favicon — el pequeño ícono en la pestaña del navegador
  • Combinación tipográfica — una tipografía display + una de cuerpo que funcionen juntas
  • Variante monocromática — versión de un solo color del logo
  • Token de diseño — un nombre para una decisión, no para un valor
  • Par accesible — un color de marca ajustado hasta cumplir WCAG AA
  • Daltonismo — por qué dos colores de marca distintos pueden colapsarse en uno

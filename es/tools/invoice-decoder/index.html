Herramienta retirada · 2026-05-08

El Decodificador de Facturas ya no está disponible.

Lo construimos como una app de navegador completa con OCR para facturas. No cumplió nuestro estándar — un OCR que lee mal media factura de Sysco no es una herramienta, es un destructor de confianza con botón de guardar. Así que lo retiramos. El objetivo siempre fue empoderarte, nunca el JavaScript: saber qué buscar en una factura. Abajo: cómo recuperar los datos que guardaste, y tres reemplazos estáticos que dan la misma respuesta en cinco minutos.

Aviso. El 2026-05-22 esta URL pasa a HTTP 410 (Gone) y los datos cifrados de facturas guardados en este navegador no serán accesibles desde esta URL. Expórtalos ahora si quieres una copia.

Recupera tus datos guardados

Tus facturas se cifraron con AES-GCM usando un secreto que tú elegiste. Escríbelo abajo para descifrar y descargar. Nada sale de esta página; el descifrado corre en tu navegador.

Saltar la exportación y borrar

Si no recuerdas tu secreto, los datos cifrados son irrecuperables. Puedes borrarlos de este navegador para liberar el espacio. Escribe BORRAR abajo para confirmar.

Tres cosas que puedes usar en su lugar

  • Leer una factura de restaurante sin OCR → Un flujo imprimible de papel-y-lápiz para la revisión semanal de facturas. Siete cosas a detectar en cinco minutos.

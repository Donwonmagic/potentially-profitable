Qué significa este puntaje

Los cuatro números detrás del puntaje — LCP, FCP, TBT, CLS — son los Core Web Vitals, las mismas señales que Google usa para rankearte en móvil. La guía sobre fugas de reservas recorre cómo cada segundo de lentitud se traduce en reservas que nunca ocurrieron.

¿Quieres ver el panorama completo? Los diagnósticos por rubro revisan velocidad móvil más flujo de reservas, menús de servicios, schema y más.

Índice de costos de ingredientes

Dónde se cotizan al mayoreo 82 ingredientes comunes de restaurante — un rango típico y una tendencia, de datos públicos de USDA, BLS y FRED — para distinguir un movimiento real de mercado de un sobreprecio de proveedor. Elige un ingrediente para su lectura, o abre Cost Pulse para verlos todos a la vez.

Abrir Cost Pulse Cómo funciona ¿Qué es un índice de costos?

Datos públicos, actualizados a diario. Última lectura: 2026-06-19. Descarga todo el índice: CSV · JSON · dominio público (CC0)

Qué es

Rangos mayoristas típicos de ingredientes comunes de restaurante, tomados de reportes públicos del USDA, BLS y FRED.

Para quién

Distingue un movimiento real del mercado del recargo de tu proveedor — antes de ajustar el precio de un plato.

En qué se diferencia

Cada número se rastrea hasta un reporte público con fecha que puedes abrir. No una cotización valorada de pago — un número que puedes verificar.

Qué se está moviendo ahora

Re-precificar = una subida que parece durar · Vigilar = un movimiento real, aún sin confirmar · Mantener = dentro de su rango normal

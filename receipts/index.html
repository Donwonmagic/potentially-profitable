What we publish. What we don’t track.

The audience for muntin.digital has been told “trust us” by every SaaS in the restaurant space and been burned. This page is the structural counter: a public diary of a one-person company — the numbers I hold myself to, recomputed from the data, not a marketing dashboard. Last updated 2026‑06‑27.

How we measure ourselves

Four north-star KPIs, reviewed weekly. The list is short on purpose — if a number stops moving, that’s the conversation, not a dashboard with thirty more.

  1. Organic-search sessions per week
  2. Tool engagement rate
  3. Workshop save rate
  4. Window engagement rate

What we track

A controlled vocabulary of about 60 events: page arrivals, AI-search landings, returning visits, article scroll depth, audio listens, glossary popovers, tool first-input, tool first-result, tool save intent, Workshop saves, newsletter signups, Window threads, form submissions, and 404s. Properties are bounded enums — no raw URLs, no path strings, no email addresses, no timestamps with second resolution.

The full event registry lives at /system/; the privacy-side disclosure lives at /privacy.html.

What we don’t track

  • No advertising cookies, no remarketing pixels, no cross-site identifiers.
  • No session replay, no heatmaps, no mouse-movement recording.
  • No keystroke logging on any tool input. Verifiable in DevTools → Network tab.
  • No email signups gated behind audit results.
  • No third-party JavaScript widgets that set cookies.
  • No fingerprinting libraries. (Plausible is cookieless and fingerprint-free.)

These are public commitments. If the policy ever changes, this page changes first — and the old version stays in git history.

Public commitments, in writing

A set of named commitments that are part of the company’s spec. Each one is a number or an absence operators can hold the company to:

  • No per-order rake. Muntin sells software and publishes data; it never takes a cut of your sales. /never/ #5.
  • Reply within 4 hours, Mon–Fri. Posted on every page, measured in Plausible.
  • Product pricing posted in writing. Muntin Ledger’s tiers and the per-invoice cost math live at ledger.muntin.digital. (The services-era tiers and offers were retired 2026-06-11; their pages 301 to /studio/.)
  • Library content licensed CC BY-NC 4.0. Quote, summarize, translate, AI-cite freely. Tools / brand / codebase explicitly not licensed for redistribution. /terms.html §4.
  • Five guarantees a platform structurally can’t make. No lock-in, no data resale, no hidden pricing, no remarketing pixel on the library, no per-order rake. /never/.
  • Three functional cookies, no banner. md_locale, lang_hint_dismissed, md_session. Plausible is cookieless. /cookies.html.
  • Maryland courts, no mandatory arbitration. Disputes go to a real courtroom in Maryland. /terms.html §10.
  • WCAG 2.2 AA target, 0 critical violations. Audited with axe-core + pa11y-ci. /accessibility.html.
  • 72-hour breach notification, 45-day Maryland PIPA filing window. If your data is ever exposed in an incident, you hear within 72 hours. /privacy.html.

What’s here now

The running record of every change lives in the changelog. The current totals, recomputed from data/site-counts.json:

  • 5 free tools, each running on your device with no signup — verifiable in DevTools → Network.

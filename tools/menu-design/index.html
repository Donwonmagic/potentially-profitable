Free tool · Menu layout for any dish count

A menu, laid out for the dishes you actually have.

Last verified: May 1, 2026

Runs in your browser. No accounts, no fetches, no tracking.

Verify it: open DevTools → Network → run the tool. The Network tab stays empty.

Canva templates assume 12 dishes. Real restaurants have 14, 27, or 53. Type your dishes, tag allergens, pick a theme, drop your logo — we lay it out onto a printable PDF that fits whatever count you have. No design software, no template fight.

You leave with: A printable PDF of your menu — your dishes, your prices, your logo, dietary & allergen glyphs next to each dish, and an auto-generated allergen key at the footer.

            What this is, and what it isn't.

            Is: an auto-layout engine for any dish count, 25 typeset themes, 22 paper sizes (letter / A4 / legal / tabloid / half-page / postcard / bi-fold / tri-fold Z / tri-fold gate / table-tent / table-card / placemat / wine-list / A2 board / A1 board / digital screen / custom). Two output flavors: a Share PDF (RGB, screen-friendly, sub-1MB) and a Print-vendor PDF (0.125″ bleed + crop marks + sRGB-tagged + PDF metadata) — your local print shop will accept this directly. Plus large-print (WCAG AAA at 18pt), QR-menu HTML, plain-text, and SSML accessible variants.

            Isn't: a true CMYK separator (commercial offset presses may want CMYK separations from a prepress service — we’ll show you how to ask), a copywriter (Menu Copy Inspector grades and rewrites descriptions), a dish-photo generator (Photo Brief handles the shoot), a translator, a profitability rater (Menu Engineering scores margin), or InDesign. Themes are intentionally constrained so output can't look amateur.

            Privacy posture: Open DevTools → Network. Type a dish, paste your menu, change theme. The Network tab stays empty. The page is static HTML plus one unminified JavaScript file you can read directly.

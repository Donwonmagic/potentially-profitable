    What this is, and what it isn't.

    Is: an auto-layout engine for any dish count, four typeset themes, letter / A4 / half-page / trifold / table-tent output, CMYK + bleed for print vendors, RGB for sharing.

    Isn't: a copywriter (Menu Copy Inspector grades and rewrites descriptions), a dish-photo generator (Photo Brief handles the shoot), a translator, a profitability rater (Menu Engineering scores margin), or InDesign. Themes are intentionally constrained so output can't look amateur.

    Privacy posture: Open DevTools → Network. Type a dish, paste your menu, change theme. The Network tab stays empty. The page is static HTML plus one unminified JavaScript file you can read directly.

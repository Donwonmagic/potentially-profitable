# Engineering Architecture & Debt

**NOT_READY**

## Thesis
The plan is unusually good at naming arithmetic defects in the ledger layer — Q-020 through Q-024 are the four real bugs, each with an objective doneWhen — but it queues no work at either end of the pipe that actually produces the sold artifact. At the output end, nothing in either repo renders a close: grep for `closeStatement` / `signedClose` / "monthly close" across `apps/api/src`, `apps/web/app` and `packages` returns nothing, and the only "close" in the plan is Q-030, a hand-built STOREFRONT page at `/close/specimen/` verified by a storefront script. The company sells a dated statement delivered like an audit opinion, and the architecture has a food-cost SCREEN, not a statement producer — so customer #1 in Q-042 gets a founder-assembled document with no receipt machinery behind it. At the input end, Q-017 deploys `apps/api` + `apps/web` only, while ingest depends on two Fly Python services whose deploy steps in `.github/workflows/deploy.yml:78-90` are four `echo "TODO"` stubs and whose one deploy script is a hard `exit 1`. Worse, the number that can end the quarter — `dollarSurvivalPct < 70` — is defined nowhere, computed by nothing, and hand-typed into a `docs/handoff/receipts/` directory that does not exist; Q-001's verify only asserts the key is non-null. Meanwhile the single largest measured quality lever in the company, `EXTRACT_VENDOR_TRUST_ACTIVE` at a measured 24% → ~62% first-pass, is switched off and appears zero times in `data/queue.json`, so CP-30 can fire on a config flag rather than a defect. The extraction engine is not robust on the mix it is sold on: the 84-87% is a yield on the vendor-trust pool (n=490), and the strategy's own named "linen service, knife route" measure 54.3% and 20.8% and are explicitly marked "hold — extraction first," which no queue item does. Finally, the storefront got a full disposition ledger for its 1,327 pages while the product's 63 API routes, 54 page routes, 6 app shells and 3 crypto implementations got no equivalent — the forgetting discipline was applied to the half of the company that costs the least to maintain.

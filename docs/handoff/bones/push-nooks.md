# Nooks and Crannies — the exhaustive unaddressed sweep

## Thesis
The plan dispositions HTML and forgets that a website is a program. All 1,327 routable pages got a record in `data/surface-disposition.json`; the 9,196-line Cloudflare Worker that serves them, its 80 API routes, its five-minute cron, its Workers-AI binding and its two KV namespaces got none — and no queue item names `src/` at all. That gap is not cosmetic: the retirement 301s for `/course/` and `/method/` live at `src/worker.js:557`, not in `_redirects`, so the single most-cited retirement in CLAUDE.md is executed by code the plan does not own. The same blindness runs the other way in the product repo, where the invoice intake path the security seat said "no item names" already exists — `apps/email-worker`, Cloudflare Email Routing, `<token>@invoices.muntin.digital` — advertised in `apps/web/lib/copy.ts:3672`, absent from Q-017's deploy scope, and coded to drop silently and never bounce. Three findings are live contradictions of published promises rather than omissions: an unauthenticated endpoint that sends stranger-supplied content to Claude Haiku on the storefront, an A/B experiment that fingerprints anonymous visitors by IP+UA and is disclosed nowhere in `privacy.html`, and `/never/index.html:441` — a permanent written guarantee that Q-010 is scheduled to break. The disposition ledger's `keep` bucket also functions as a default: every surface no seat examined (admin, `/window/`, `/system/`, `/receipts/`, `/claims/`, `/never/`, `/ai/`, `/status/`, `/trust/`, `/studio/`, `/account/`, `/sign-in/`) landed in the 406 maintained pages by rule R0/R1 without a human deciding it should be maintained. Nothing in the plan covers the non-routable estate at all — 200 MB of `brand/` regenerated on every deploy, `llms-full.txt` as a freeze-proof distribution channel, two stale feeds, 76 runbooks, three migration roots, and a fourth product component (`ledger-spec/`) that appears in no CLAUDE.md and no seat's inventory. The correct response is not 40 new queue items; it is three: one disposition pass over runtime code equivalent to what `surface-disposition.json` did for pages, one kill-switch commit that turns off everything running for a retired line, and one item that reconciles the plan against the site's own published "nevers" before Q-010 ships.

## Findings

Freezing a page does not stop it. `data/surface-disposition.json` records disposition per page and has no field for the JS a page executes.

Zero items name the storefront Worker. The `/course/` and `/method/` 301s CLAUDE.md presents as done are implemented at `src/worker.js:557` — not in `_redirects` (which contains no `/course` or `/method` line). - **The storefront runs an unauthenticated public LLM endpoint and a Whisper transcription path, with a production `ai` binding, on the domain that publishes the never-reaches-a-language-model promise — and has no sub-processors page.** — `src/worker.js:4487` — `env.AI.run('@cf/anthropic/claude-haiku-4-5', ...)` inside `/api/brand-dossier`, reachable by POST with a caller-supplied URL and signals block. `src/lib/window-attachments.js:554` — `env.AI.run('@cf/openai/whisper')` on Window voice notes. `wrangler.jsonc` declares `"ai": {"binding": "AI"}` in the production config. The only sub-processors document in either repo is `/home/user/Muntin-Invoice-Decoder/docs/sub-processors.md`; the storefront has none.
- **Q-010 is scheduled to break a permanent written guarantee published on a `keep`-classed trust page, and that page also carries the killed tier language and a hostname the product does not use.** — `never/index.html:440-441`: "I will never hide pricing behind a call." — "Muntin Ledger's tiers are posted in writing at ledger.muntin.digital, with the per-invoice cost math published beside them — no call, no form, no 'contact us for a quote.'" The sentence also names TIERS (withdrawn by ADR-030/ADR-013) and `ledger.muntin.digital`. No gate, no honesty-debt entry, and no queue item reconciles the plan against `/never/`.
- **A live A/B experiment fingerprints anonymous visitors by IP + User-Agent and is disclosed on no privacy surface; its own registry file is decorative.** — `src/worker.js:1636` — `EXPERIMENTS` is a hardcoded frozen object with `window-cta-copy` at `status: 'running'`. `bucketForRequest` (≈1655-1663) computes `SHA-256(ip + '|' + ua + '|' + day)` and stamps `data-experiment`/`data-treatment` on `<html>` via HTMLRewriter (≈1778-1790). `grep -ci experiment privacy.html cookies.html` returns 0 and 0, while `privacy.html:460` describes analytics as "No cookies, no identifiers." Separately, `data/experiments.json`'s own `_doc` states "src/worker.js HTMLRewriter reads this file" — it does not; the live set is in code, so the registry can drift silently.
- **The invoice intake path the security seat called unnamed already exists, is advertised in shipped copy, drops silently, and is in no deploy item.** — `apps/email-worker/wrangler.toml`: "Makes the advertised 'forward an invoice email to <token>@invoices.muntin.digital' path work"; shared D1 `muntin-api`, reads `org_inbox_tokens`. `apps/email-worker/src/index.ts:26-31`: "Unknown/revoked token => DROP (structured log, never bounce)"; "No invoice attachment, oversize, or non-invoice => DROP." `apps/web/lib/copy.ts:3672` and `copy.es.ts:2934` describe the address to operators.

# Site coverage ledger — every surface

**True scope:** 1,329 routable pages · 1,396 HTML files · **~925,000 lines** (EN+ES).
A "fully informed reinvention needs consideration of every surface" (founder). This ledger
tracks that to 100%.

**Method definition (honest):**
- **Hand-authored** surfaces → **read in full**, every line.
- **Generated** corpora (a builder + template + data produce them) → **known completely** by
  reading the *builder + template + the driving data + verifying uniformity* + reading the
  hand-authored instances. Reading N near-identical generated clones adds no knowledge.
- **ES mirrors** → knowledge via the EN source + the i18n/parity system (locale-parity +
  hreflang gates); not separately deep-read.

## The big finding (why this matters)

A large share of the mass is **retired website-services-era content** off the cost-intelligence
funnel: the *frozen* `course` (27pg), `learn` (25pg), `method` (20pg), ~2/3 of the `library`
(website/SEO/Google articles) + their glossary terms. **The reinvention is as much a PRUNE +
REFOCUS as a redesign** — surface the cost-intelligence core, retire/redirect the agency-era mass.

## Open methodological choice (founder's call)

For the **generated corpora** (glossary 172 / cost-index 100 / sheets 55 / course 27), the
recommendation above = **complete knowledge via builder + template + data + verify + sample**
(far less waste, same knowledge for deterministic output). The alternative = **literal
line-by-line read of every generated instance** (~10× the cost, near-zero added knowledge).
Recommending the former; flag if you want the latter.

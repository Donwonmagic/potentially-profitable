# Off-site foundation — earning non-branded AI citations (the slow, highest-ceiling lever)

> Wave-3 of the non-branded program. On-site (pillars, comparisons, schema) gets us *eligible*;
> off-site corroboration is what actually wins **recommendation** queries ("best restaurant web designer",
> "who builds restaurant websites") in ChatGPT/Perplexity/Google AI — because those engines lean on what the
> *rest of the web* says, especially Reddit, review platforms, and "best of" roundups. Most of this is Don's
> action (accounts, profiles, honest participation). Prioritized by impact ÷ effort.

## The mental model
AI engines, for "best/recommended X" queries, disproportionately cite: (1) third-party "best X" listicles,
(2) review/directory platforms with structured ratings, (3) Reddit/forum threads, (4) the entity's own
consistent presence (NAP + sameAs) across the web. We've built the on-site entity graph; this is about
getting **corroboration** so an engine has multiple independent sources naming Muntin Digital.

## TIER 1 — highest impact, do first
1. **B2B / web-design directories with structured ratings (AI cites these heavily for "best web design" queries):**
   - **Clutch.co** — the big one; create a profile, get 2-3 client reviews. Clutch is frequently cited by AI for agency/web-design recommendations.
   - **The Manifest** (Clutch sister), **DesignRush**, **GoodFirms**, **UpCity** — create profiles; they syndicate into "best web design company in Maryland / for restaurants" lists.
   - Angle to claim on each: "restaurant website design", "Silver Spring / Washington DC metro", "one-person studio / boutique".
2. **Map/search business profiles beyond Google (consistency = entity strength):**
   - **Bing Places for Business** and **Apple Business Connect** (Apple Maps) — claim both; AI assistants (esp. Apple/Bing-backed) read these. Use the EXACT same NAP as the Google Business Profile (locality-only: Silver Spring, MD).
3. **Get included in existing "best restaurant website builder/designer" roundups:**
   - The publishers we cited in the comparison draft (getsauce, restolabs, menubly, websitebuilderexpert, etc.) run roundups. Pitch a short, honest "add a custom/independent option" note with the muntin.digital comparison page as the reference. Being *named in a roundup* is a direct AI-citation source.

## TIER 2 — Reddit / Q&A (AI pulls recommendations from these constantly)
- Subreddits where "do I need a restaurant website / who should build it / Wix vs custom" come up: **r/restaurateur**, **r/smallbusiness**, **r/Entrepreneur**, **r/restaurant**. 
- The ONLY approach that works (and that won't get you banned or backfire): answer the question genuinely and completely, link a *relevant* muntin.digital library page **only when it directly answers**, disclose you run the studio. Helpful-first; the citation value comes from the thread existing + ranking, not from a hard sell. (This matches the site's voice — no growth-hacking.)
- **Quora**: answer "best restaurant website builder", "how much does a restaurant website cost" with the honest framing from our pages.
- Reuse our own sourced content (pricing ranges, the ownership/commission-model framing) so answers are substantive.

## TIER 3 — Wikidata / knowledge graph (do only when there's independent coverage)
- A **Wikidata item** strengthens the entity in knowledge graphs that AI reads. BUT Wikidata has a **notability bar** — a brand-new one-person studio item can be deleted for lack of independent, reliable sources. So: pursue Wikidata **after** Tier 1 (once Clutch/roundup/press mentions exist to cite as references), not before.
- When ready, the item: label "Muntin Digital"; description "restaurant web design studio in Silver Spring, Maryland"; P31 (instance of) = business; P17 = United States; P159/P131 = Silver Spring, Maryland; P856 (official website) = https://muntin.digital; P112 (founded by) = Don Goldstein; P452 (industry) = web design; plus the social sameAs (Instagram/LinkedIn/Facebook handles already in our Organization schema). Cite each statement to an independent source.

## TIER 4 — earned mentions (slow, compounding)
- A guest post or interview on a restaurant-operations or local-business outlet → a backlink + a named mention AI can cite.
- Podcasts (restaurant-operator / small-business shows) — being named on a show with a transcript online is AI-citable.
- Local press (Silver Spring / Montgomery County small-business features).

## What I (the site) already did to make this pay off
- The on-site **entity graph** (Organization/LocalBusiness/Person `@id`s + `sameAs` + the broadened description) so every off-site mention resolves to ONE entity.
- The **comparison + pillar pages** give roundup editors and Reddit answers something substantive + linkable to point at.
- **Plausible** (once live) will show which AI engines actually refer traffic, so we double down on what's working.

## Honest expectation
Off-site is the slowest lever — weeks to months — and it's mostly relationship/profile work only you can do. Tier 1 (Clutch + Bing/Apple + roundup inclusion) is the highest-leverage starting point and realistically a few hours of setup that compounds.

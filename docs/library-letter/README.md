# Library Letter — quarterly newsletter drafts

The quarterly send that goes to operators after they finish the six-week
[email drip](../email-drip/). Written by Don, voiced first-person, same
contract as the rest of the site (see [/methods/#voice-contract](https://muntin.digital/methods/#voice-contract)).

Footer copy on every page says: *"I send a short note when I publish
something — four notes a quarter, no funnels."* The Library Letter is
that note.

## Drafts in this folder

| File | Quarter | Status |
| ---- | ------- | ------ |
| `2026-q2-may-wave.md` | Q2 2026 | Ready to send |

## How to send

Pasted into the same tool that drives the drip (Buttondown, or whatever
the studio's email tool is at send time). The subject line is the only
piece that doesn't come from this file — it's authored fresh per send
so the inbox view differentiates the letters.

## Voice + length

Same contract as the drip: first-person, mid-formal, predicate sentences,
no hedge tokens, no marketing language. Length 250–400 words. Subject
under 50 chars. Open with a single specific sentence; close with a single
specific call to action (almost always a link to one new artifact, not
five).

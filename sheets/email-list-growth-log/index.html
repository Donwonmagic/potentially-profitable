When to use it

Pull this sheet out when —

  • Monthly — first week, pulling subscriber stats from your sender (Mailchimp, Klaviyo, ConvertKit, etc.).
  • Before launching a new capture point — table tent, QR code, online-order checkbox — to set a baseline.
  • When unsubscribes spike — the source attribution names which channel is misaligned with what you send.
Common mistakes

What operators get wrong

  • Counting sign-ups without engagement. A list of 5,000 with 6% open rate is worth less than 800 at 40%.
  • Using a single capture form with no source tag — without source, the ROI question is unanswerable.
  • Sending the same cadence to every source. Reservation sign-ups want different content than a checkout opt-in.

When to use it

Pull this sheet out when —

  • Before commissioning new signage, awnings, or printed graphics — your printer needs every spec.
  • When ordering reorders — the spec sheet is the proof the new batch matches the old.
  • Before a permit application — the spec is the document you submit to the city.
Common mistakes

What operators get wrong

  • Pantone codes for a CMYK print job — the print shop will substitute and you won't see it until install.
  • Missing the mounting detail. "Flush mount" vs "stand-off" changes the install bill, not just the look.
  • No bleed / safety zone marked. The print shop trims; what was on the edge is now off the edge.

When to use it

Pull this sheet out when —

  • Weekly — fifteen minutes, with the GBP / Yelp / Tripadvisor inboxes open.
  • After every 1- or 2-star review — those need a response within 48 hours, every time.
  • When a complaint theme repeats — the log surfaces the pattern that one-off reviews hide.
Common mistakes

What operators get wrong

  • Responding only to 5-stars. Google reads the response rate on negatives as a quality signal.
  • Generic responses ("thanks for your feedback") on detailed complaints. The reviewer wrote 200 words; respect them.
  • Logging the response date but not the THEME tag. Without themes, you cannot run the pattern review.

  • Before any menu redesign — the shortlist anchors the layout.
Common mistakes

What operators get wrong

  • Listing every dish on the printed menu. The shortlist is the website's showcase, not the full menu.
  • Forgetting to note allergens. The host stand will be asked, and a wrong answer costs reviews.
  • Not running plate-cost on the shortlist. The dishes you feature should be the dishes that pay.

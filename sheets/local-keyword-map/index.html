Common mistakes

What operators get wrong

  • Targeting the same keyword on three pages. Google picks one; the other two split the signal and suppress all three.
  • Using city-only keywords when neighborhood-modified terms convert better — "silver spring brunch" beats "silver spring restaurant" for intent.
  • Mapping by gut instead of by query data. Search Console says what people actually typed; trust it.

Restaurant subtypes

Bar / pub / brewery

taproom, gastropub, cocktail room

Restaurants

Bars, pubs, taprooms, breweries, wine bars, cocktail rooms — drink-led spots where private-party events and happy-hour clarity drive conversion. Schema: BarOrPub, Brewery, Winery, Distillery.

Why it matters

The audit adds an age-gate check (weight 2.0× for bar-pub, 0 for every other subtype) and treats the private-events page as revenue-critical. Cocktail and draft lists rotate constantly, so the HTML menu check runs heavier here too. Platform fingerprints: Tripleseat for events, OpenTable/Resy/SevenRooms for reservations. Keyword signals: cocktails, craft beer, on tap, happy hour, gastropub, taproom, speakeasy, brewery.
